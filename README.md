# imbandita.com

The public website for Imbandita, served by GitHub Pages at https://imbandita.com.

- `index.html` is the whole site, one file, Arabic and English. Source: the cleaned landing page in `halmowafy/imbandita`, `business/landing/imbandita-landing-2026-10-06.html`.
- Sign up and Log in open the live system at https://app.imbandita.com.
- Arabic is set in Tajawal (free, Google Fonts).
- DNS lives in GoDaddy: `@` has the four GitHub Pages A records, `www` is a CNAME to `amernajjari.github.io`. `app` and `api` point at the app server and are not touched here.
